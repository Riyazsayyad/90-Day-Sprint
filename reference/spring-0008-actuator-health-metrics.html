Actuator Cheat Sheet

  • Liveness = restart; readiness = LB membership
  • Do not DB-check liveness
  • management.port + deny /env /heapdump /loggers publicly
  • Micrometer: HTTP, JVM/GC, Tomcat, Hikari
  • Latency: metrics → thread dump (actuator or jcmd) → GC; heapdump last
  • /conditions = auto-config report
