Servlet Stack Cheat Sheet

LB → Tomcat worker → Filters → DispatcherServlet → HandlerMapping → Controller → Service → Repo
  • Blocking I/O holds the worker; max threads ≠ DB capacity
  • Hikari often the real concurrency limit
  • Filter (servlet) vs Interceptor (MVC) vs @ControllerAdvice (exceptions)
  • MDC/ThreadLocal: clear in finally
  • Boot 3.2: spring.threads.virtual.enabled — I/O wait, not extra DB
  • Dump threads (jcmd) when latency spikes — JVM S08
