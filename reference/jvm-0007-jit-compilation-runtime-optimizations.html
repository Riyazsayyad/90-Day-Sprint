JIT & Runtime Optimizations Cheat Sheet

Warmup, tiers, escape analysis

1. Compilation Tiers

Interpreter → C1 (fast compile) → C2 (deep optimize)

Tiered compilation default on server JVM. Warmup required.

2. Hot Methods & OSR

  • Invocation counter → compile threshold
  • OSR — compile hot loop inside active frame

3. Key Optimizations

  • Inlining — callee body at callsite
  • Devirtualization — monomorphic virtual call → direct
  • Dead code elimination / constant folding
  • Loop unrolling
  • Lock elision — if provably uncontended (preview)

4. Deoptimization

Profile assumption fails → drop native code → interpreter/recompile.

Triggers: megamorphic callsite, escaped object, lock contention.

5. final & Monomorphic Sites

  • final methods/classes — stable JIT target (oop-0015)
  • One receiver type at callsite → inline likely
  • Many types → megamorphic → no inline

6. Escape Analysis

  • Object doesn't leave method/thread scope
  • Scalar replacement — fields → locals/registers
  • May skip heap/TLAB allocation

7. JIT Logging (awareness)

-Xlog:jit+compilation=info
-XX:+PrintCompilation  (legacy)

8. Enterprise

  • Cold start — serverless/K8s scale-from-zero pays warmup
  • JMH — warmup before measure
  • GraalVM Native — AOT startup vs peak JIT (mention)
