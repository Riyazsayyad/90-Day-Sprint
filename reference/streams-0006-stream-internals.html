Stream Internals Cheat Sheet

Module 02 capstone — execution engine

1. Two Phases

Phase What happens
Build Link AbstractPipeline nodes via previousStage. No traversal.
Run Terminal evaluate() → wrap sinks → traverse spliterator.

2. Pipeline Node Types

  • Head — source spliterator/supplier, parallel flag, onClose
  • StatelessOp — map, filter, flatMap, peek (fuse)
  • StatefulOp — sorted, distinct, limit, skip (barriers)
  • TerminalOp — not a pipeline node; drives evaluation

3. Evaluation Paths

  • evaluate(TerminalOp) — entry point
  • wrapAndCopyInto — sequential push through sink chain
  • evaluateParallel — split → Node trees → merge

4. Sink Lifecycle

begin(size) → accept(element)* → end()
cancellationRequested() — short-circuit upstream

Chain built backward from terminal via wrapSink().

5. Spliterator Characteristics

Flag Enables
SIZED/SUBSIZEDPre-size buffers
ORDEREDEncounter order preserved
SORTEDSkip redundant sort
DISTINCTSkip redundant distinct
NONNULLSkip null checks
IMMUTABLESkip CME checks
CONCURRENTSafe parallel source

6. StreamOpFlag

Pipeline-level metadata: DISTINCT, SORTED, ORDERED, SIZED, SHORT_CIRCUIT. Combined per stage via combineOpFlags(). unordered() clears ORDERED.

7. StreamShape

REFERENCE | INT_VALUE | LONG_VALUE | DOUBLE_VALUE — typed pipelines and sinks avoid boxing.

8. Stateful Barriers

Op Barrier behavior
sorted()Buffer all → sort → flush
distinct()Buffer seen keys
limit(n)Count + cancel
skip(n)Discard first n

9. Parallel Internals

  • trySplit() → AbstractTask on ForkJoinPool
  • Stateful stages → opEvaluateParallel() → Node merge
  • Pipeline combiner ≠ Collector combiner
  • Ordered parallel merges cost more — see Parallel Streams ref

10. Edge Cases

  • flatMap — child pipeline per element (allocation hotspot)
  • Stream.concat — loses SIZED; ConcatSpliterator
  • generate/iterate — infinite; needs short-circuit
  • onClose — head pipeline cleanup handlers
  • CME — collection spliterator modCount check

12. Interview One-Liners

  • Stream ≠ collection — pipeline metadata only
  • Lazy = no traversal until terminal
  • Sink = push/fused loop, not Iterator pull
  • sorted() = full buffer + O(n log n)
  • Thread dump ReferencePipeline$Head = stream running
