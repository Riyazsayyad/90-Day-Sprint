ApplicationContext & Lifecycle Cheat Sheet

Module 05 S02

1. Pipeline

Config → BeanDefinition → instantiate → DI → @PostConstruct → singleton cache → @PreDestroy on close

2. Context vs Factory

  • BeanFactory: getBean, definitions
  • ApplicationContext: + events, i18n, AOP integration, eager singletons

3. Scopes

  • singleton (default) — one / context
  • prototype — new at lookup; destroy not tracked like singleton
  • request / session / application / websocket — web

4. Traps

  • Spring singleton ≠ enum singleton
  • Prototype into singleton = one instance unless ObjectProvider / scoped proxy
  • Constructor cycles fail (Boot 3) — refactor, don’t enable circular refs
  • @Lazy moves failure from startup to first use

5. Ordering

  • @DependsOn — init order
  • @Order — among same-type callbacks/filters
