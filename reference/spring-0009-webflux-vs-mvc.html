WebFlux vs MVC Cheat Sheet

  • MVC: worker (or VT) per blocking request
  • WebFlux: event loop; blocking JDBC on loop = stall
  • Mono 0..1; Flux 0..N; subscribe starts work
  • Not automatically faster
  • JPA CRUD → MVC ± virtual threads
  • Gateway / streaming / reactive DB → WebFlux
