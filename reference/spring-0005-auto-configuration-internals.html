Auto-Configuration Cheat Sheet

@SpringBootApplication = @SpringBootConfiguration + @EnableAutoConfiguration + @ComponentScan
  • Discovery: META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports (Boot 3)
  • spring.factories EnableAutoConfiguration key: legacy, removed in 3.0
  • @AutoConfiguration + @ConditionalOnClass/Property/MissingBean/WebApplication
  • User @Bean → OnMissingBean false → back-off
  • exclude / spring.autoconfigure.exclude
  • Debug: --debug Condition Evaluation Report; /actuator/conditions
