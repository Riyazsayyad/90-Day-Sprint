AOP & Transactions Cheat Sheet

Caller → Proxy → TransactionInterceptor → Target → commit/rollback
  • JDK proxy: interfaces; CGLIB: subclass. Boot: proxy-target-class=true (CGLIB)
  • final class/method, private, new Service() → no advice
  • this.foo() skips proxy (self-invocation)
  • Rollback default: RuntimeException/Error; checked commits unless rollbackFor
  • REQUIRED join; REQUIRES_NEW suspend + new tx
  • readOnly = hint, not a write firewall
  • Tx bound to thread (platform); don’t assume hop to another thread
