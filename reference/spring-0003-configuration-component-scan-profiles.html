Configuration, Scan & Profiles Cheat Sheet

  • Default scan: package of @SpringBootApplication + subpackages
  • @Component / @Service / @Repository / @Controller — same core DI
  • @Bean — third-party / explicit construction; name = method name
  • @Configuration (proxyBeanMethods true): sibling @Bean calls → singleton
  • @Profile + spring.profiles.active / SPRING_PROFILES_ACTIVE
  • Missing bean: scan → profile → name → then conditions (S04)
