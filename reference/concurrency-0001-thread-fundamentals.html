Thread Fundamentals Cheat Sheet

Lifecycle, start vs run, daemon, coordination

1. Process vs Thread

  • Process: own address space
  • Thread: shared heap, private stack
  • Races live on shared heap objects

2. Concurrency vs Parallelism

  • Concurrency: tasks in progress (may time-slice)
  • Parallelism: tasks run at same instant on multiple cores
  • Parallel streams = data parallelism, not general concurrency

3. Create & Start

API Note
new Thread(runnable).start() Classic platform thread
Thread.ofPlatform().start(r) Builder (Java 21+)
Thread.ofVirtual().start(r) Virtual; always daemon
t.run() No new thread — same call stack

Prefer Runnable over extending Thread. Start once only.

4. Thread.State

  • NEW → RUNNABLE ↔ BLOCKED / WAITING / TIMED_WAITING → TERMINATED
  • BLOCKED = waiting to enter synchronized
  • WAITING = wait / join / park (no timeout)
  • TIMED_WAITING = sleep / timed wait/join

5. Coordination

  • join() — wait for termination
  • interrupt() — cooperative cancel; restore flag on catch
  • sleep — does not release monitors

6. Daemon

  • Non-daemon keeps JVM alive
  • Daemon alone → JVM may exit
  • setDaemon(true) before start()

7. Production One-Liners

  • No unbounded new Thread per request — use executor
  • Shared mutable heap = race until synchronized/volatile/JMM proven
  • Uncaught exception kills the thread, not necessarily the JVM
