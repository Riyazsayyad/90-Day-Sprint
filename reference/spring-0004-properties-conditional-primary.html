Properties & Conditions Cheat Sheet

  • Environment: overlay sources; env vars relaxed-bind to properties
  • @Value = one key; @ConfigurationProperties = typed group + @Validated
  • @ConditionalOnProperty / OnClass / OnMissingBean / OnWebApplication
  • Autowire: 0 → NoSuchBean; 2+ → Qualifier / @Primary / NoUniqueBean
  • @Qualifier is per injection point; @Primary is default candidate
