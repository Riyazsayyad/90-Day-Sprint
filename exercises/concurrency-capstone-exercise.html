Quick Review — In-Browser Drills

No IDE needed. Answers in <details>.

  1. Drill A: newFixedThreadPool(8) under spike — first failure?

    1. Unbounded queue grows until OOM.
    2. Pool rejects at eight threads.
    3. Creates ninth thread immediately.
    4. Tasks run on common pool.
    Answer

    A — S05: unbounded LinkedBlockingQueue.

  2. Drill B: volatile int + count++ from 100 threads?

    1. Lost updates — not atomic RMW.
    2. Fully atomic without any lock.
    3. Visibility only — count stays 0.
    4. CME on every increment call.
    Answer

    A — S03 + S06.

  3. Drill C: VT + hot synchronized block on JDBC?

    1. Pinning — carrier held blocked.
    2. Virtual thread cannot enter sync.
    3. Immediate IllegalMonitorState.
    4. Auto upgrade to platform thread.
    Answer

    A — S08: use ReentrantLock or shrink scope.

  4. Drill D: thenApply when next step returns CF?

    1. Use thenCompose — flattens nested CF.
    2. Use thenApply — flattens nested CF.
    3. Use thenRun — flattens nested CF.
    4. Use thenAccept — flattens nested CF.
    Answer

    A — S07: flatMap vs map.
